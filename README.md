# Student Record Management System

A beginner-friendly Python project for managing student records using CRUD operations and file-based data storage.

## 📌 Project Overview

The Student Record Management System is a console-based Python application developed as part of Module 2 – Functions, Files & Exception Handling.

The project demonstrates how core Python concepts can be combined to build a practical application.

## ✨ Features

- Add new student records
- View all student records
- Search for a student
- Update student information
- Delete student records
- Store student data using JSON
- Handle invalid input and runtime errors
- Use Python functions for modular programming

## 🛠️ Concepts Covered

- Python Functions
- Parameters and Arguments
- Return Values
- Lambda Functions
- List Comprehensions
- File Handling
- JSON Data Handling
- CRUD Operations
- Exception Handling
- try-except-finally
- Virtual Environments
- Git and GitHub

## 🔄 CRUD Operations
